# 🚌 OSARE — East Africa Transport API

A fast, multi-modal transport search platform and API for East African local commuter and regional transit.

---

## ⚡ Quickstart

```bash
# Clone & set up environment
git clone [https://github.com/osare/ea-transport-api.git](https://github.com/osare/ea-transport-api.git)
cd ea-transport-api
python3 -m venv venv && source venv/bin/activate
pip install -r requirements.txt

# Start the server
python server.py
